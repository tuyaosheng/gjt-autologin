# 莞教通学生便捷登录助手（gjt-autologin）

面向学校机房场景的一套小工具：老师维护一份学生总表，为每个班生成一个**独立、可双击运行的登录小程序**；学生打开后从名单里选出自己的名字，程序会自动打开浏览器、跳转到"莞教通"（东莞市互联网+教育大平台）的学生便捷登录页，并自动填好证件号码和班级登录码，学生只需要看图输入验证码、点击登录即可——不用记密码，也不用自己敲身份证号和登录码。

老师这边还配了一个图形化管理面板，一键生成/重新生成各班的登录程序，以及每两天更新一次全班共用的"便捷登录码"。

> ⚠️ **重要声明**：本项目是非官方社区工具，与"莞教通"平台、东莞市教育局没有任何隶属或合作关系。它只是自动化了学生本人已经被授权执行的操作（用自己的证件号 + 班主任下发的便捷登录码登录），**不会、也无法绕过验证码等安全机制**，不涉及未授权访问。请仅在你对相关学生数据拥有合法管理权限的场景下使用（例如班主任、年级组长），并自行承担数据安全与合规责任。

## 这个项目解决什么问题

莞教通的"学生便捷登录"需要学生自己输入证件号码 + 班主任提供的便捷登录码 + 图形验证码。在机房上课、需要几十个学生短时间内依次登录同一个系统的场景下，靠学生手动输入证件号和一长串登录码，效率低、也容易输错。

这个工具把"选人、打开浏览器、跳转登录页、填证件号、填登录码"这几步自动化，学生只需要在弹出的小窗口里选自己的名字、点一下登录，然后照着图形验证码敲进去、点登录，就完成了——**验证码这一步刻意保留人工输入，不做任何自动识别或绕过**，因为这是网站自身防自动化的安全机制。

## 功能一览

- **学生端**（`login_tool.py`，打包成每班一个独立 exe）
  - 搜索 + 列表选人，同名学生自动用身份证后 4 位消歧
  - 自动打开 Edge、自动填好证件号码和班级登录码
  - 点击登录后按钮立即禁用并给出"正在打开浏览器"的反馈，防止界面卡顿期间被连续点击、背后开出多个浏览器
  - Windows 系统级互斥锁：同一台电脑上不会被重复打开第二份
  - 学生名单在编译时就以简单混淆编码内置进 exe，不以明文文件形式随程序分发
- **教师端命令行工具**
  - `build_class_exe.py`：从总表按班级筛选，现场编译出该班专属 exe（可以只编译一个班，也可以 `all` 一次性编译全部班级）
  - `update_login_codes.py`：批量读取登录码表格，写入各班的 `login_code.txt`
- **教师端图形管理面板**（`manage_panel.py`，可再打包成 `管理面板.exe`）
  - 多选班级列表 + 一键生成，后台线程运行、实时滚动日志
  - 一键读取登录码表格并更新所有班级
  - 自动识别哪张表格是总表、哪张是登录码表（按表头判断）
  - 支持"浏览选择"任意位置的表格文件，以及"下载空白模板"
  - 启动时自动检测本机是否有可用的 Python + PyInstaller

## 工作原理

```
学生总表.xlsx ──┐
                ├─▶ build_class_exe.py ──▶ PyInstaller ──▶ <班级>自动登录程序.exe
便捷登录码.xlsx ─┤                                              │
                │                                              ▼
                └─▶ update_login_codes.py ──▶ login_code.txt（与 exe 放在一起，纯文本，随时可替换）

学生双击 exe → 选自己的名字 → Selenium 打开 Edge → 自动填证件号+登录码 → 学生手动输验证码并登录
```

- 每个班的 exe 只内置**这一个班**的学生名单（姓名 → 身份证号），编译时经过简单混淆编码，不是明文可读的文件，避免学生用记事本之类的工具直接打开偷看同班同学的身份证号。
- 便捷登录码是**按班共用**的一个码，独立存放在 `login_code.txt` 里，和 exe 放在同一文件夹；每两天老师更新一次这个文本文件即可，不需要重新编译或重新分发 exe。
- 自动化基于 [Selenium](https://www.selenium.dev/) 驱动 Microsoft Edge，浏览器窗口在程序退出后依然保持打开（`detach` 模式），驱动进程本身则会在填完表单后被清理掉，避免机房电脑上残留大量后台进程。

> 本仓库**不包含**任何真实学生数据、真实登录码，也不包含编译产物（exe/build/dist）——`.gitignore` 已经把这些排除在外。你需要自备学生总表和登录码表格才能实际使用（见下文模板下载）。

## 环境要求

- Windows 10/11（Selenium 部分依赖 Microsoft Edge）
- [Microsoft Edge](https://www.microsoft.com/edge) 浏览器
- Python 3.9+（**生成/编译**功能所在的这台电脑必须要装，见下方"已知限制"）
- pip 依赖：见 [`运行/requirements.txt`](运行/requirements.txt)（`openpyxl`、`selenium`、`pyinstaller`）

学生实际使用登录程序的机房电脑**不需要**安装 Python——那些电脑拿到的是编译好的独立 exe。

## 快速开始

```bash
git clone https://github.com/<your-account>/gjt-autologin.git
cd gjt-autologin/运行
pip install -r requirements.txt

# 方式一：图形界面（推荐）
python manage_panel.py

# 方式二：命令行
python build_class_exe.py        # 生成登录程序
python update_login_codes.py     # 更新登录码
```

## 详细使用说明

### 1. 准备两张表格

在 `运行/` 目录下放两张 Excel 表格，**文件名任意**，程序会根据表头自动识别：

**学生总表**（表头必须精确包含这四列，顺序不限，可以有其他额外列）

| 年级 | 班级 | 姓名 | 身份证号码 |
|---|---|---|---|
| 七年级 | 1 | 张三 | 110101201501011234 |

**便捷登录码表**（一行一个班）

| 班级 | 便捷登录码 |
|---|---|
| 七年级1班 | 12345678 |

> `班级` 这一列要写完整班级名（比如"七年级1班"），需要和后面生成的文件夹名完全一致。

不想手动建表的话，用管理面板里的"下载空白模板…"按钮，会直接生成一份表头和示例行都填好的空白表格。

### 2. 生成学生端登录程序

**图形界面**：打开管理面板，"① 生成登录程序"区域勾选班级（支持多选/全选），点击"开始生成"。

**命令行**：

```bash
python build_class_exe.py
```

按提示选择表格，然后：
- 输入某个编号：只编译这一个班级
- 输入 `all`：一次性编译总表里的所有班级（几十个班大概十几到二十分钟）

生成完成后，`运行/dist_output/<班级>/` 下会有两个文件：

- `<班级>自动登录程序.exe`（例如"七年级1班自动登录程序.exe"，学生名单已内置在里面）
- `login_code.txt`（初始是占位文字，需要填真实登录码）

### 3. 下发到机房电脑

用 U 盘把某个班的这两个文件一起拷贝到该班每台机房电脑的**桌面**上（同一个文件夹里）。一个班的文件夹只给这个班，避免出现在其他班级的电脑上。

### 4. 学生怎么用

1. 双击桌面上的 `<班级>自动登录程序.exe`
2. 在弹出的窗口里搜索或滚动找到自己的名字，点一下选中
3. 点击"登录"，程序自动打开浏览器并填好证件号码和登录码
4. 自己看浏览器里的图形验证码，输入后点击网页上的"登录"按钮完成登录

### 5. 每两天更新便捷登录码

**图形界面**：改好登录码表格后，点"② 更新便捷登录码"区域的"读取并更新登录码"。

**命令行**：

```bash
python update_login_codes.py
```

会自动把每个班最新的登录码写进对应 `dist_output/<班级>/login_code.txt`。**不需要**重新编译或重新拷贝 exe——把更新后的 `login_code.txt` 用 U 盘覆盖到机房电脑桌面上即可生效。

### 6. 学生名单变化了怎么办

转学、身份证号更正等情况：更新总表里对应的行，针对该班重新运行一次生成（图形界面或命令行都行），重新下发新 exe；登录码文件可以照旧沿用。

### 7. 把管理面板也打包成 exe

```bash
cd 运行
python -m PyInstaller --onefile --noconsole --icon panel_icon.ico --name 管理面板 manage_panel.py
```

生成的 `管理面板.exe` 需要和 `login_tool.py`、`crypto_utils.py`、`build_class_exe.py`、`update_login_codes.py`、`paths.py`、`login_icon.ico` 这些源码文件放在同一文件夹里才能正常工作（见下方"已知限制"）。

## 数据安全与隐私

- 学生总表、登录码表格、生成的 `login_code.txt`、`dist_output/` 里的编译产物都属于学生个人信息，`.gitignore` 已经把这些排除在版本控制之外，**不会**被提交到这个公开仓库。
- 每个班的 exe 只内置对应班级的学生名单，不含其他班级或年级的信息。
- 学生名单在 exe 内部使用固定密钥的 XOR + Base64 简单混淆，**这不是安全加密**，只是防止有人直接用文本工具翻出明文身份证号；不要指望它能抵御专业逆向。
- 验证码环节全程留给学生本人手动完成，工具不做任何形式的自动识别或绕过。

## 已知限制

1. **验证码无法绕过**：这是网站自身的安全机制，工具只自动填证件号和登录码，验证码必须人工输入。
2. **"生成登录程序"离不开 Python + PyInstaller**：不管是直接运行脚本，还是把管理面板打包成 exe，"生成"这一步的本质都是现场调用 PyInstaller 编译出新的学生端 exe，这台电脑本身必须装有 Python + PyInstaller，没法把这个能力"打包"进一个完全独立、任意电脑都能用的 exe 里。"更新登录码"功能则没有这个限制，可以在任何电脑上独立运行。
3. **Edge / WebDriver 版本匹配**：Selenium 依赖的 `msedgedriver.exe`（如果你手动放了一份到项目目录）版本需要和电脑上的 Edge 大版本一致。不放的话会用 Selenium Manager 自动联网下载，需要电脑能访问外网。
4. **U 盘分发的人工成本**：机房电脑之间通常没有共享网络盘，登录码更新后仍需要物理拷贝到每台电脑，这一步无法完全自动化。

## 常见问题

**Q: 程序打不开浏览器 / 提示找不到驱动？**
A: 大概率是内置/使用的 `msedgedriver.exe` 版本和电脑上的 Edge 版本不匹配。到 [Microsoft Edge WebDriver](https://developer.microsoft.com/microsoft-edge/tools/webdriver/) 下载对应版本放进项目目录，重新生成 exe。

**Q: 表格提示"缺少必须的列"？**
A: 检查表头是否精确包含"年级""班级""姓名""身份证号码"（登录码表则是"班级""便捷登录码"）。多余的列没关系，但这几个列名不能改。

**Q: 学生双击程序没反应/卡顿？**
A: 已知问题在近期版本中修复——点击登录后按钮会立即禁用并给出反馈，避免连续点击开出多个浏览器；同一台电脑也不能重复打开第二份程序。如果仍然卡顿，优先检查电脑本身性能和是否有大量历史遗留的浏览器/驱动进程。

莞教通学生便捷登录助手 — 教师使用说明
========================================

一、首次准备（在你自己的电脑上）
1. 安装依赖（只需一次）：
   pip install -r requirements.txt
2. 把总表 xlsx（年级/班级/姓名/身份证号码）放在本项目文件夹里。
3.（可选）如果机房电脑联网不稳定，建议提前下载与机房 Edge 浏览器版本
   匹配的 msedgedriver.exe，放到本项目文件夹里，构建时会自动打包进 exe。
   不放的话，程序运行时会用 Selenium 自带的 Selenium Manager 自动联网
   下载驱动，需要机房电脑能访问外网。

二、生成登录工具
1. 在本项目文件夹运行：
   python build_class_exe.py
2. 按提示选择表格，然后：
   - 输入某个编号：只编译这一个班级
   - 输入 all：一次性编译总表里的所有班级（班级多的话会花不少时间，
     每个班大约几秒到十几秒，96 个班大概十几到二十分钟，期间不用管它）
3. 编译完成后，会在 dist_output\<班级>\ 下生成两个文件：
   - login_tool_<班级>.exe
   - login_code.txt（初始内容是占位文字，需要你改成真实登录码，或者
     直接用下面"三、更新便捷登录码"里的方法批量填）
4. 用 U 盘把这两个文件一起拷贝到该班机房每台电脑的桌面上（同一个文件夹里）。
   用 all 一次性编译的情况下，dist_output 里每个班一个文件夹，按文件夹
   名对应拷给相应班级即可。

三、更新便捷登录码（每两天一次）
1. 打开项目目录下的"便捷登录码.xlsx"，把每个班对应的最新登录码填好
   （表格两列：班级、便捷登录码，班级名要和 dist_output 里的文件夹名
   完全一致，例如"七年级1班"）。
2. 运行：
   python update_login_codes.py
   它会自动把每个班最新的登录码写进 dist_output\<班级>\login_code.txt。
3. 用 U 盘把每个更新过的 login_code.txt 逐台覆盖到对应机房电脑桌面。
4. 不需要重新运行 build_class_exe.py，也不需要重新拷贝 exe。

四、如果学生名单变化了（转学、身份证号更正等）
1. 更新总表 xlsx 里对应的行。
2. 重新运行一次 python build_class_exe.py，针对该班重新生成 exe。
3. 重新下发新的 exe（登录码文件可以照旧沿用，不用换）。

五、学生怎么用
1. 双击桌面上的 login_tool_<班级>.exe。
2. 在弹出的窗口里，搜索或者滚动找到自己的名字，点一下选中。
3. 点击"登录"按钮，程序会自动打开浏览器并填好证件号码和登录码。
4. 学生自己看浏览器里的图形验证码，输入后点击网页上的"登录"按钮完成登录。
   （验证码必须人工输入，这是网站自身的安全机制，无法也不应该绕过。）

六、如果 Edge 浏览器升级导致登录工具打不开浏览器
1. 说明打包进 exe 的 msedgedriver.exe 版本和新版 Edge 不匹配。
2. 到 https://developer.microsoft.com/microsoft-edge/tools/webdriver/
   下载与机房电脑当前 Edge 版本一致的 msedgedriver.exe，放进本项目文件夹。
3. 重新运行 python build_class_exe.py 针对每个班重新生成 exe 并重新下发。

七、数据安全提醒
- 总表 xlsx 和生成的 login_code.txt / dist_output 里的内容都属于学生个人
  信息，不要提交到任何公开的代码仓库或网盘分享链接（本项目的 .gitignore
  已经把这些文件排除在版本控制之外）。
- 每次生成的 exe 只包含对应班级的学生名单，不含其他班级或年级的信息。

莞教通学生便捷登录助手 — 教师使用说明
========================================

一、首次准备（在你自己的电脑上）
1. 安装依赖（只需一次）：
   pip install -r requirements.txt
2. 把总表 xlsx（年级/班级/姓名/身份证号码）和"便捷登录码.xlsx"
   （班级/便捷登录码）放在本项目文件夹里，文件名随意，脚本会自动识别。
3.（可选）如果机房电脑联网不稳定，建议提前下载与机房 Edge 浏览器版本
   匹配的 msedgedriver.exe，放到本项目文件夹里，构建时会自动打包进 exe。
   不放的话，程序运行时会用 Selenium 自带的 Selenium Manager 自动联网
   下载驱动，需要机房电脑能访问外网。

二、日常操作：管理面板（推荐）
1. 运行 manage_panel.py（或双击打包好的 manage_panel.exe）：
   python manage_panel.py
2. 面板顶部会显示环境检测结果、识别到的总表和登录码表格文件名。
3. "① 生成登录程序"：在班级列表里勾选要生成的班级（可以多选，也可以点
   "全选"），点击"开始生成"，下方日志会实时显示进度，完成后在
   dist_output\<班级>\ 下能看到对应文件。
4. "② 更新便捷登录码"：改好"便捷登录码.xlsx"后，点一下"读取并更新登录码"，
   会自动把每个班最新的码写进对应文件夹，日志里会提示哪些班成功、哪些班
   还没生成过 exe。
5. 注意：manage_panel.exe 即使打包成了 exe，"生成登录程序"这一步仍然需要
   这台电脑本身装有 Python + PyInstaller（因为这一步的本质是现场编译新
   exe，没法绕开），所以管理面板建议留在你自己这台开发电脑上用，不要指望
   随便一台电脑都能用它来生成程序。"更新登录码"这部分不涉及编译，任何
   装了这个 exe 的电脑都能用。

三、日常操作：命令行方式（不想用图形界面时的备选）
1. 生成登录程序：
   python build_class_exe.py
   按提示选择表格，然后：
   - 输入某个编号：只编译这一个班级
   - 输入 all：一次性编译总表里的所有班级（96 个班大概十几到二十分钟）
2. 更新便捷登录码：
   python update_login_codes.py
   自动读取"便捷登录码.xlsx"并写入各班 login_code.txt。

四、生成结果 & 下发到机房
1. 编译完成后，会在 dist_output\<班级>\ 下生成两个文件：
   - <班级>自动登录程序.exe（比如"七年级1班自动登录程序.exe"）
   - login_code.txt（初始内容是占位文字，需要改成真实登录码）
2. 用 U 盘把这两个文件一起拷贝到该班机房每台电脑的桌面上（同一个文件夹里）。
3. 每两天更新登录码后，只需要用 U 盘把新的 login_code.txt 覆盖到机房电脑
   桌面，不需要重新生成或重新拷贝 exe。

五、如果学生名单变化了（转学、身份证号更正等）
1. 更新总表 xlsx 里对应的行。
2. 用管理面板或 python build_class_exe.py 针对该班重新生成 exe。
3. 重新下发新的 exe（登录码文件可以照旧沿用，不用换）。

六、学生怎么用
1. 双击桌面上的 <班级>自动登录程序.exe。
2. 在弹出的窗口里，搜索或者滚动找到自己的名字，点一下选中。
3. 点击"登录"按钮，程序会自动打开浏览器并填好证件号码和登录码
   （点击后按钮会短暂变成"正在打开浏览器，请稍候…"并禁止再点，避免
   重复点击开出多个浏览器；如果不小心重复打开了程序本身，第二个会
   自动提示"已经在运行了"并退出，不会真的再开一份）。
4. 学生自己看浏览器里的图形验证码，输入后点击网页上的"登录"按钮完成登录。
   （验证码必须人工输入，这是网站自身的安全机制，无法也不应该绕过。）

七、如果 Edge 浏览器升级导致登录工具打不开浏览器
1. 说明打包进 exe 的 msedgedriver.exe 版本和新版 Edge 不匹配。
2. 到 https://developer.microsoft.com/microsoft-edge/tools/webdriver/
   下载与机房电脑当前 Edge 版本一致的 msedgedriver.exe，放进本项目文件夹。
3. 用管理面板或 python build_class_exe.py 针对每个班重新生成 exe 并重新下发。

八、把管理面板自己也打包成 exe（可选）
在项目文件夹运行：
   python -m PyInstaller --onefile --noconsole --icon panel_icon.ico ^
       --name 管理面板 manage_panel.py
生成的"管理面板.exe"在 dist\ 目录下，运行时同样要求这台电脑装有
Python + PyInstaller（见上面第二节的说明），并且要和 build_class_exe.py、
update_login_codes.py、login_tool.py、crypto_utils.py、paths.py、
login_icon.ico 这些源码文件放在同一个文件夹里。

九、数据安全提醒
- 总表 xlsx、"便捷登录码.xlsx"和生成的 login_code.txt / dist_output 里的
  内容都属于学生个人信息，不要提交到任何公开的代码仓库或网盘分享链接
  （本项目的 .gitignore 已经把这些文件排除在版本控制之外）。
- 每次生成的 exe 只包含对应班级的学生名单，不含其他班级或年级的信息。

# 莞教通学生便捷登录助手 — 设计文档

日期：2026-09-17

## 背景与目标

教师持有本校学生的年级/班级/姓名/身份证号总表（`初一学生信息（请勿全年级下发）.xlsx`）。莞教通网站（tyyh.dgjy.net）提供"学生便捷登录"入口，登录需要：证件号码 + 班主任下发的便捷登录码（每班一个，每两天更换）+ 图形验证码。

目标：在学校机房，每台学生电脑上运行一个小工具，学生只需从名单里选出自己的名字，工具自动打开浏览器并填好证件号码和当前班级登录码，学生看图输入验证码后点击登录即可，无需自己记忆或手动输入证件号/登录码。

严格要求：每次下发（拷到学生机）的数据包只能包含**一个班级**的学生名单，不能泄露全年级/全校数据。

## 源数据格式

文件：`初一学生信息（请勿全年级下发）.xlsx`，`Sheet1`，表头：

| 年级 | 班级 | 姓名 | 性别 | 身份证号码 | 须知 |
|---|---|---|---|---|---|

- `年级`：文本，如"七年级"
- `班级`：数字，如 `1`
- 导出时只使用 `姓名` 和 `身份证号码`，按 `年级`+`班级` 过滤；`性别`、`须知` 忽略。
- 若同班存在重名，登录工具在列表中以"姓名（身份证后4位）"消歧，不展示完整证件号。

## 组件

### 1. 教师端导出/构建工具（`build_class_exe.py`，教师本机运行，需要 Python + PyInstaller）

- 读取总表 xlsx，列出所有"年级+班级"组合供选择（命令行交互即可）。
- 选定一个班级后：
  1. 过滤出该班学生的 姓名→身份证号 映射，做简单混淆编码（XOR + Base64，固定密钥），生成一个临时的 Python 数据模块。
  2. 调用 PyInstaller，把 `login_tool.py` 连同这份数据模块、`msedgedriver.exe` 一起打包成**单个文件**的 exe（`--onefile`，driver 作为内置资源随包释放到运行时临时目录）。
  3. 产物重命名为 `login_tool_初一1班.exe`（按班级命名），连同一份初始 `login_code.txt` 一起放到教师指定的输出目录。
- 教师下发给该班机房电脑的**只有两个文件**：`login_tool_初一1班.exe` + `login_code.txt`，用 U 盘拷贝到每台学生机的**桌面**。
- 换班/改名单（转学、身份证号更正等）：重新跑一次构建工具，重新下发新 exe。日常两天一次的登录码更新**不需要**重新构建或重新下发 exe。

### 2. 学生端登录工具（`login_tool.py`，构建时按班级编译进独立 exe）

运行时假设：与 `login_code.txt` 在同一目录（即桌面）；学生名单已在编译时内置在 exe 内部，不依赖外部数据文件。

流程：
1. 启动时从内置的（编译进 exe 的）编码数据中解码出本班姓名列表，展示一个 Tkinter 窗口：搜索框 + 姓名列表。
2. 学生输入/选择自己的姓名，点击"登录"。
3. 程序读取同目录下 `login_code.txt` 的当前内容（每次点击登录都重新读取，不缓存，保证老师更新后立即生效）。
4. 用 Selenium 启动 Edge（driver 从 exe 内置资源释放到临时目录后加载），打开：
   `https://tyyh.dgjy.net/tpass/login?service=...`
   点击"学生便捷登录"，自动填入该学生的证件号码和班级登录码。
5. 弹出提示框："请查看浏览器中的验证码图片并手动输入，然后点击登录"。程序到此结束自动化，不代填、不代提交验证码和登录按钮。
6. 界面全程不显示身份证号或登录码明文；这两个值只在内存中传递给浏览器表单。

### 3. 数据编码

学生名单以固定密钥的简单混淆（XOR + Base64）编译进 exe 内部，目的仅是防止有人直接用工具从 exe 里粗略搜出明文身份证号，不是抵御专业逆向的加密方案。

### 4. 登录码更新流程

机房电脑之间无共享网络盘。更新方式：教师每两天在自己电脑上修改 `login_code.txt` 的内容，用 U 盘逐台覆盖学生机桌面上的同名文件即可，**不需要重新构建或重新分发 exe**。

## 已知限制

1. **验证码无法绕过**：这是网站自身的安全机制（防自动化爆破），工具只自动填前两项，验证码必须学生本人手动输入后点击登录。这是与用户确认过的"半自动"方案，优点是不因网站更换验证码样式而失效。
2. **Edge/driver 版本匹配**：Selenium 依赖的 `msedgedriver.exe` 版本需与机房电脑安装的 Edge 大版本一致。若学校电脑自动更新了 Edge，需要更换对应版本的 driver 文件（`使用说明.txt` 里会写清楚检查方法和下载渠道）。
3. **U盘分发的人工成本**：班级数量多时，每两天挨台电脑更新 `login_code.txt` 有一定人工操作量，但相比手动录入证件号/登录码仍大幅省事；本设计不引入网络自动更新机制（无共享盘可用，也不假设机房电脑能访问外部服务器）。

## 测试计划

- 用总表里的示例/测试数据跑通构建工具，确认生成的某班 exe 里只包含该班学生（其他班级/年级的名字不会出现在列表中）。
- 在一台本机 Windows 环境验证生成的 exe：选人 → 自动打开 Edge → 自动填好证件号+登录码 → 停在验证码步骤。
- 用重名测试数据验证列表消歧逻辑。
- 更新同目录下的 `login_code.txt` 后重新点击登录，确认新登录码即时生效（未被缓存）。
- 确认 exe 单独拷贝到一台干净的 Windows 电脑（无 Python）也能正常运行，且能正确释放并调用内置的 `msedgedriver.exe`。

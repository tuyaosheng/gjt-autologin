# 莞教通学生便捷登录助手 — 设计文档

日期：2026-09-17

## 背景与目标

教师持有本校学生的年级/班级/姓名/身份证号总表（`初一学生信息（请勿全年级下发）.xlsx`）。莞教通网站（tyyh.dgjy.net）提供"学生便捷登录"入口，登录需要：证件号码 + 班主任下发的便捷登录码（每班一个，每两天更换）+ 图形验证码。

目标：在学校机房，每台学生电脑上运行一个小工具，学生只需从名单里选出自己的名字，工具自动打开浏览器并填好证件号码和当前班级登录码，学生看图输入验证码后点击登录即可，无需自己记忆或手动输入证件号/登录码。

严格要求：每次下发（拷到学生机）的数据包只能包含**一个班级**的学生名单，不能泄露全年级/全校数据。

## 源数据格式

文件：`初一学生信息（请勿全年级下发）.xlsx`，`Sheet1`，表头：

| 年级 | 班级 | 姓名 | 性别 | 身份证号码 | 须知 |
|---|---|---|---|---|---|

- `年级`：文本，如"七年级"
- `班级`：数字，如 `1`
- 导出时只使用 `姓名` 和 `身份证号码`，按 `年级`+`班级` 过滤；`性别`、`须知` 忽略。
- 若同班存在重名，登录工具在列表中以"姓名（身份证后4位）"消歧，不展示完整证件号。

## 组件

### 1. 教师端导出工具（`export_tool.py`，教师本机运行）

- 读取总表 xlsx，列出所有"年级+班级"组合供选择（命令行交互即可，教师本机已有 Python，无需打包）。
- 选定一个班级后，在教师指定目录下生成一个"班级包"文件夹（如 `初一1班登录工具/`），内含：
  - `login_tool.exe`（学生端登录工具，各班共用同一份，来自统一构建产物，直接拷贝）
  - `msedgedriver.exe`（与机房 Edge 版本匹配的驱动，随包附带）
  - `students.dat`（**仅本班**学生的姓名→身份证号映射，简单编码，非明文）
  - `login_code.txt`（纯文本一行，当前班级登录码，教师手动维护）
  - `使用说明.txt`（给教师看的：如何更新登录码、如何在 Edge 升级后更换 driver）
- 教师用 U 盘把整个班级文件夹拷贝到该班机房电脑的**桌面**上，每台电脑一份完整拷贝。

### 2. 学生端登录工具（`login_tool.py` → PyInstaller 打包为 `login_tool.exe`）

运行时假设：与 `students.dat`、`login_code.txt` 在同一目录（即桌面上的班级文件夹）。

流程：
1. 读取并解码 `students.dat`，展示一个 Tkinter 窗口：搜索框 + 姓名列表。
2. 学生输入/选择自己的姓名，点击"登录"。
3. 程序读取 `login_code.txt` 当前内容（每次读取，不缓存，保证老师更新后立即生效）。
4. 用 Selenium 启动 Edge（`msedgedriver.exe`），打开：
   `https://tyyh.dgjy.net/tpass/login?service=...`
   点击"学生便捷登录"，自动填入该学生的证件号码和班级登录码。
5. 弹出提示框："请查看浏览器中的验证码图片并手动输入，然后点击登录"。程序到此结束自动化，不代填、不代提交验证码和登录按钮。
6. 界面全程不显示身份证号或登录码明文；这两个值只在内存中传递给浏览器表单。

### 3. 数据编码

`students.dat` 使用固定密钥的简单混淆（XOR + Base64，内置在 exe 中），目的仅是防止学生用记事本/Excel 直接打开偷看同班同学的身份证号，不是抵御专业攻击的加密方案。

### 4. 登录码更新流程

机房电脑之间无共享网络盘。更新方式：教师每两天在自己电脑上修改对应班级包里的 `login_code.txt`，用 U 盘逐台覆盖学生机桌面班级文件夹里的同名文件即可，**不需要重新构建或重新分发 exe**。

## 已知限制

1. **验证码无法绕过**：这是网站自身的安全机制（防自动化爆破），工具只自动填前两项，验证码必须学生本人手动输入后点击登录。这是与用户确认过的"半自动"方案，优点是不因网站更换验证码样式而失效。
2. **Edge/driver 版本匹配**：Selenium 依赖的 `msedgedriver.exe` 版本需与机房电脑安装的 Edge 大版本一致。若学校电脑自动更新了 Edge，需要更换对应版本的 driver 文件（`使用说明.txt` 里会写清楚检查方法和下载渠道）。
3. **U盘分发的人工成本**：班级数量多时，每两天挨台电脑更新 `login_code.txt` 有一定人工操作量，但相比手动录入证件号/登录码仍大幅省事；本设计不引入网络自动更新机制（无共享盘可用，也不假设机房电脑能访问外部服务器）。

## 测试计划

- 用总表里的示例/测试数据跑通导出工具，确认生成的班级包只含该班学生。
- 在一台本机 Windows 环境验证 `login_tool.exe`：选人 → 自动打开 Edge → 自动填好证件号+登录码 → 停在验证码步骤。
- 用重名测试数据验证列表消歧逻辑。
- 更新 `login_code.txt` 后重新点击登录，确认新登录码即时生效（未被缓存）。
